# 每天学5个字 · 汉字启蒙工作台

一个给小朋友（也适合任何零基础起步的人）用的汉字学习工作台。每天 5 个字，90 个字分 6 关，靠象形字卡、组词练习和闯关积分把字真正记住。

纯静态单文件，不依赖任何框架、CDN 或字体服务，双击打开就能用，也可以部署到任何静态托管。

## 打开方式

- 在线使用：**https://tlc520520.github.io/china-textbook/**
- 本地使用：把 `index.html` 下载到电脑，双击用浏览器打开

手机上用：浏览器打开上面的链接 → 分享 → 添加到主屏幕，就和 App 一样了。

## 四个模块

### 1. 今日学字（象形字卡）

每天固定 5 个新字，按「天地自然 → 人与身体 → 动物世界 → 生活器物 → 动作关系 → 会意进阶」的顺序往下排。

- 卡片点一下翻面，正面是字形（部分字带手绘象形示意图），背面是拼音、部首、笔画、字义、象形来历、组词和例句
- 背面「我记住了」按钮 = 这个字算掌握，+10 积分
- 顶部进度条显示今天 5 个字掌握到第几个
- 下方 14 天学习足迹热力图，看得到自己哪几天偷懒了

### 2. 组词练习

根据今天学的字自动出题，两种题型交替：

- **选出含有这个字的词语** —— 干扰项来自其他字的词，必须真的认识这个字才选得对
- **选字填空** —— 把词语里的字挖掉，从形近/同音字里挑出正确的

答对 +5 分；答错的字自动进错题本。支持键盘 `1`~`4` 选答案、`Enter` 下一题。

### 3. 闯关积分

6 个关卡，每关 15 个字。通关条件：该关 15 字全部掌握 + 组词正确率 ≥ 80%，通关奖励 50 积分。

积分可以在奖励清单里兑换（默认预置了看动画片、冰淇淋、新书、动物园四个），也可以自己加奖励、自己定积分价格。兑换后显示「已领取」，由家长兑现。

### 4. 错题知识

- **错题本**：练习答错的字自动收录，记录错了几次、错在哪种题型；答对会逐步抵扣次数，错题熟了自动消失
- **全部字库**：90 个字全量检索，支持按**汉字 / 拼音 / 部首 / 词语**查（拼音不用带声调，输 `ri` 也能找到「日」）
- 点任意一条打开知识卡，看完整的象形来历

## 数据说明

- 所有数据存在**你自己浏览器的 localStorage** 里，不上传任何服务器，没有账号体系
- 换设备 / 清理浏览器缓存前，请用右上角「导出备份」存一份 JSON，在新设备用「导入恢复」合并回去
- 学习记录累计到 30 条时会提醒备份
- 首次打开预置了少量示例数据（昨天学了 4 个字 + 1 条错题），可以在「更多设置 → 清空示例数据」一键清掉，从头开始

## 技术实现

- 单文件 `index.html`，CSS / JS / 图标全部内联，零外部请求
- 图标全部是内联 SVG `path`，插图是手绘 SVG 象形示意
- 架构分三层单向调用：数据层（localStorage 读写）→ 计算层（纯函数）→ 渲染层（只写 DOM）
- 渲染函数之间互不调用，所有联动统一走 `refreshAll()` 单一入口，避免互相触发导致死循环
- PC 端左侧导航，移动端底部 Tab；按钮最小触控区 44px，输入框字号 16px 防 iOS 缩放，适配 iPhone 底部安全区

```js
['日','rì','日',4,'独体字','太阳；白天；一天','甲骨文的「日」画成一个圆圈……',['日光','日出','生日','日记'],'日出东方，天亮了。']
// 字、拼音、部首、笔画、结构、字义、象形来历、组词、例句
```

改完保存刷新即可，已学的记录不受影响。象形示意图在 `PICT` 对象里，用 `viewBox="0 0 100 100"` 的内联 SVG 片段。
